DeejAI: The Master Curator EcosystemProject Blueprint \& Roadmap1. The North Star (Project Vision)The goal is not to discover new music, but to listen to more of the music you already love with zero friction. The system acts as a highly personalized, context-aware "Smart Radio" that outsmarts standard streaming algorithms by relying on real completion rates and sonic similarity, ensuring your local library never feels like a forgotten archive.2. System ArchitectureA modular, decoupled ecosystem where DeejAI acts as the "Master Curator" (Middleware) sitting between the music files and the user interface.The Media Server (Navidrome): Running on the Raspberry Pi (192.168.0.29:4533). Acts as the delivery pipe, handling raw audio streaming and standard metadata via the Subsonic API.The Smart Curator (DeejAI API): Running on Windows (via Docker). A headless Python REST API that holds the vector embeddings (mp3tovec.p), the behavioral database (plays.db), and the scoring logic. It fetches the catalog from Navidrome, re-ranks it, and dictates what the client sees and plays.The Data Ingestion Loop (SpotifySkipTracker): A background Electron app tracking live Spotify playback and writing skips/completions directly to plays.db, ensuring the local model learns from all listening habits.The Client (React Native iOS App): A custom, intent-driven mobile interface. It pings DeejAI for the curated UI/queue, resolves track IDs via Navidrome, and plays audio seamlessly using react-native-track-player.3. The RoadmapPhase 1: Backend API Hardening \& Command CenterSmart Curator API: Rewrite station\_server.py into a robust REST API exposing /api/home, /api/recommend (with live parameters like epsilon, vibe, context), and /api/played.Anti-Tunneling \& Deduplication: Implement $\\epsilon$-greedy exploration and a ring buffer for recent tracks to prevent sonic loops.Library Sync Engine: Automate the ingestion of new music. A background thread that runs MP3ToVec.py strictly on new differential files and hot-reloads the embeddings.Server Dashboard: Build an HTML Admin Dashboard (localhost:8051/admin) to visualize plays.db stats, tweak baseline math variables, and trigger library syncs.Phase 2: Docker Packaging \& SecurityDocker Compose: Package the DeejAI Python server and Navidrome into a unified stack.Reverse Proxy \& Auth: Deploy Caddy to securely expose DeejAI to music.myhouse.fyi without a tunnel, enforcing strict API Key (Bearer) authentication.Phase 3: The React Native ScaffoldInitialization: Set up the React Native project in VS Code with react-native-track-player for background audio and lock-screen controls.Middleware Connection: Establish dual API connections—fetching UI and queues from DeejAI, and streaming raw audio from Navidrome.Phase 4: Expansion \& PolishIntent-Driven UI: Build out the "Start Gym Radio" and "Jump Back In" frontend components.CarPlay Integration: Extend the react-native-track-player UI to the car dashboard
